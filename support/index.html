Support

Room for Duo · Safari extension for iPhone Duo

Questions, a site that doesn't look right, or an idea? Email support@higherbarapps.com. Include the website address and whether the iPhone Duo was folded or open.

Set up

  1. Open Room for Duo and tap Open Extension Settings.
  2. Turn on Allow Extension and set All Websites to Allow.

Common questions

A page looks unchanged. In Safari, open the page menu, tap Room for Duo and allow it on every website. Safari asks again after an update adds permissions.

The first page I opened looks narrow. A page opened from the address bar's top hit can load before Safari runs extensions. Reload it.

A site looks wrong when folded. From Room for Duo in Safari's page menu, switch that site between Wide, Wide + Text and Off.

I want a site's phone version when unfolded. From Room for Duo in Safari's page menu, set that site to Off in the Open group.

Does it work on other iPhones? No. Room for Duo is made for iPhone Duo. Other iPhones already use the full width in Safari, so it leaves pages alone.
